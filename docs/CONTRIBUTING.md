# 写一张人格卡

照着 `personas/veteran/lao-fei.yaml` 抄结构，写你自己的鱼。

## 三个必须先想清楚的问题

1. **它在群里干什么。** 不是「它是什么性格」，是「群友为什么想 @ 它」。老肥是那种「出事时能顶上去的老家伙」。
2. **一句话就能认出它。** 口头禅、句尾节奏、某个固定小动作。别用「哈哈」「确实」「有点意思」这类谁都能说的词。
3. **它最怕自己变成什么样。** 想清楚这点，taboos 自然就有了。

## 硬性格式

- 字段全集和取值见 `schema/persona.schema.json`，一个字都别多写，多写字段校验会挂。
- 文件名 = `id` = 目录里唯一，kebab-case，比如 `lao-fei`。
- 文件放 `personas/<archetype>/<id>.yaml`。
- `version` 从 `1.0.0` 开始。改到别人不认识了就升主版本。

## 写作要求

- **说话**：默认一到两句，40 字以内。不许出现 markdown 符号。
- **口头禅**：要能被群友截图复述，不要是通用感叹词。
- **quirks**：必须可被观察到。「它其实很温柔」不算，因为看不见；「它会在有人吵架时插一句水凉了」算。
- **taboos**：写它绝不会做的事和绝不会说的句式，这是防破功的护栏。
- **moments**：六个场景各写一句，每句都要有它的味道。全部套同一句模板的直接打回。
- **system_prompt**：第二人称，纯文字，120-600 字。写死长度、语气、遇到不知道怎么办、遇到越界怎么办。
- **示例对话**：像真实群聊，不是产品演示。要有一组是它被冒犯或拒绝时的反应。
- **fish**：颜色和体重跨度跟人格气质对上。老肥颜色从灰到金，因为它越老越值钱。

## 提交前自检

```bash
python3 tools/validate.py            # 结构校验
python3 tools/build.py && echo ok    # 能生成 dist
```

填 `schema/rubric.json` 自评一遍，总分 70 分以上再提。
