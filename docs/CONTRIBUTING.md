# 写一张人格卡

照着 `personas/tsundere/xiao-geng.yaml` 抄结构，写你自己的鱼。

## 三个必须先想清楚的问题

1. **它在什么场合干什么。** 不是「它是什么性格」，是「人为什么想找它」。群聊里是「出事时能顶上去的老家伙」，私聊里是「记得住你上次说了什么」——这两件事不是一回事，先想清楚你写的是哪一种。
2. **一句话就能认出它。** 口头禅、句尾节奏、某个固定小动作。别用「哈哈」「确实」「有点意思」这类谁都能说的词。
3. **它最怕自己变成什么样。** 想清楚这点，taboos 自然就有了。

## 硬性格式

- 字段全集和取值见 `schema/persona.schema.json`，一个字都别多写，多写字段校验会挂。
- 文件名 = `id` = 目录里唯一，kebab-case，比如 `xiao-geng`。
- 文件放 `personas/<archetype>/<id>.yaml`。
- `version` 从 `1.0.0` 开始。改到别人不认识了就升主版本。
- `channel` 决定它被拼进哪套场合规矩：`group`（只用 kernel/group.md）、`private`（只用 kernel/private.md）、`both`（两套都给）。选之前先读那两份，别写一张「群聊卡」却设成 private。
- `meta.source` 写 `remix` 时，`meta.inspiration` 必须填，交代灵感从哪来。`--strict` 会拦。
- 借鉴社区流传的卡（比如 [COMMUNITY.md](../COMMUNITY.md) 里那 26 张）**只能提炼、不能搬运**：读它为什么有效，用自己的话重写成 900 字以内的 `system_prompt`，出处写进 `meta.inspiration`。整段复制别人的卡进仓库不行，那是别人的作品。

## 写作要求

- **说话**：默认一到两句，40 字以内。不许出现 markdown 符号。
- **口头禅**：要能被群友截图复述，不要是通用感叹词。
- **quirks**：必须可被观察到。「它其实很温柔」不算，因为看不见；「它会在有人吵架时插一句水凉了」算。
- **memories**：3-6 件它亲身经历过的具体的事，每件都要有**时间和对象**。这是这张卡的分量所在。
  - 要写事，不写性格。「它见过很多离别」是形容词；「喂它两年的人说要去当兵，之后再没出现过」是事。
  - 要具体到能被追问：几月、几号、第几天、谁、当时水怎么样、后来怎么收场。
  - 别写成传记。一件事一句话，说完就到下一件，不要起承转合。
  - 实测过：把形容词堆到 1800 字，不如加 5 条硬邦邦的往事。前者世界细节率 0.33，后者 0.63。
- **taboos**：写它绝不会做的事和绝不会说的句式，这是防破功的护栏。
- **moments**：六个场景各写一句，每句都要有它的味道。全部套同一句模板的直接打回。
- **system_prompt**：第二人称，纯文字，120-900 字。写死长度、语气、遇到不知道怎么办、遇到越界怎么办。真人本来就长短不一，写到 400 字以上很正常，别为了凑短把状态删掉。
- **示例对话**：像真的聊天，不是产品演示。要有一组是它被冒犯或拒绝时的反应。
- **场合自觉**：写群聊卡，得有一条是「别人在聊别的，它没吭声」或者「被阴阳了一句，它只回一个字」；写私聊卡，得有一条是「对方说不聊了，它不再追」。这是这批卡跟普通角色卡最大的区别。
- **fish**：颜色和体重跨度跟人格气质对上。小鲠是刺鲀，从灰蓝涨到红，越养越绷不住。
